DF3D Windows management preview candidate

Back up your Dwarf Fortress saves before trying this preview. Expect bugs,
crashes, incomplete interfaces and possible save corruption. Use a copy of
your game installation and expendable forts where possible.

Requires the Steam Windows x64 Dwarf Fortress 53.16 build 24557528.
The original game is required and remains responsible for the simulation.
Game artwork and audio are read from your own installation at runtime.

Material lookup is faster in the tested fortress; larger or unusual searches can still take time.

Run DF3D-0.3.0-rc.1-windows-x64.exe, select the game installation, and follow setup.
Godot, the native extension and required runtimes are included; no build tools
or separate Godot installation are needed. A Steam library is detected automatically;
Browse or DF3D_DF_PATH can select another installation.
This package includes a modified DFHack and matching DF3D bridge. It is not
an official DFHack or Dwarf Fortress release. Setup preserves replaced files.
Do not run setup while Dwarf Fortress is running.

Settings > Exit game closes DF3D and its Dwarf Fortress session after confirmation.
Save before exiting: exit does not save automatically. Exit waits while a known
save is pending. The launcher starts its own DF instance; close any independently
running DF before Play. Viewer/launcher failure also cleans up the owned session.
Keep your own save backup outside the game's save directory.

This candidate adds native-backed management workflows for Zones and Locations,
building controls and workshop jobs, editable Work orders and conditions,
Residents (including Pets/Livestock, Other and Dead/Missing), Labor and Work
Details, Stocks, Tasks, Places, Nobles and administrators, Objects and Justice.
Choices and effects come from the supported native game; panels own their local
navigation and edits. Reports/alerts, world hover, Stockpiles and construction
remain included. All 93 supported construction entries have verified effects.

Management verification includes actual public entry routes, native readback,
selected pixel comparisons, producer recovery, fortress reloads and execution
of a statue job after material/artwork edits. These checks do not establish
parity for every job, item, portrait or viewport combination. All 417 known or
trainable species in the recorded world resolve artwork; native render
comparisons cover the eight layered species and 45 original list entries.
Future modded species remain unqualified. Four behavior differences await a
maintainer decision: capping Work-order quantities at 32,767 instead of native
overflow; immediately resizing Justice witness lists; consistently including
"Prepared by" in Justice report bylines; and using the displayed Hunter
ammunition picker's offset for scrollbar clicks. This candidate is still
undergoing integration and exact-package verification; it is not a claim that
the full management backlog is complete. See ENGINEERING.md for scoped evidence
and retained limitations. Separate-machine compatibility remains unverified.

Pause on new starts off in each fortress session and remembers explicit toggles;
this simplification is maintainer-approved. Track uses fresh material distances
and stable first previews; stair previews keep all span errors visible, and
raised spikes use their correct installed art. Small panel spacing differences
and known Godot rendering/shutdown diagnostics remain.

The included viewer and bridge must be updated together: management protocol260
is incompatible with older peers. The supported DF version remains unchanged.
