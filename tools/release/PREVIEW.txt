DF3D Windows preview

Back up your Dwarf Fortress saves before trying this preview. Expect bugs,
crashes, incomplete interfaces and possible save corruption. Use a copy of
your game installation and expendable forts where possible.

Requires the Steam Windows x64 Dwarf Fortress 53.16 build 24557528.
The original game is required and remains responsible for the simulation.
Game artwork and audio are read from your own installation at runtime.

Material lookup is faster in the tested fortress; larger or unusual searches can still take time.

Run DF3D-0.2.0-windows-x64.exe, select the game installation, and follow setup.
Godot, the native extension and required runtimes are included; no build tools
or separate Godot installation are needed. A Steam library is detected automatically;
Browse or DF3D_DF_PATH can select another installation.
This package includes a modified DFHack and matching DF3D bridge. It is not
an official DFHack or Dwarf Fortress release. Setup preserves replaced files.
Do not run setup while Dwarf Fortress is running.

Settings > Exit game closes DF3D and its Dwarf Fortress session after confirmation.
Save before exiting: exit does not save automatically. Exit waits while a known
save is pending. The launcher starts its own DF instance; close any independently
running DF before Play. Viewer/launcher failure also cleans up the owned session.
Keep your own save backup outside the game's save directory.

This release includes Reports/alerts and construction across the native build
catalog. An animated activity marker now indicates pending construction material
loading/placement. Closing a panel also makes Play respond immediately.
Construction uses DF's native material candidates, ordering and placement checks.
The viewer remains responsive during lookup and holds simulation during the picker.
Pause on new starts off in each fortress session and
remembers explicit toggles; this simplification is maintainer-approved.
All 93 supported construction entries have verified construction effects.
Track uses fresh material distances and stable first previews; stair previews
keep all span errors visible, and raised spikes use their correct installed art.
Small panel spacing differences and known Godot rendering/shutdown diagnostics
remain. Other unfinished screens are not made complete by this release.
See ENGINEERING.md for verification scope and retained limitations.

The included viewer and bridge must be updated together: management protocol54
is incompatible with older peers. The supported DF version remains unchanged.
